# Session Handoff - November 28, 2025

## Session Summary

This session fixed a critical bug in the queue processor that was causing emails to be incorrectly blocked.

### Bug Fixed: Sliding Window Limit Applied When Disabled

**Problem**: Queue processor was reporting "no SMTP server available - all servers at capacity" even when the sliding window feature was disabled (`app.message_sliding_window = false`).

**Root Cause**: In `cmd/init.go:762`, the `SlidingWindowLimit` was being set to `settings.AppMessageSlidingWindowRate` (value: 16) regardless of whether `settings.AppMessageSlidingWindow` was enabled.

**Fix Applied**: Modified `cmd/init.go` lines 746-768 to only set sliding window settings when the feature is enabled:

```go
// Before (buggy):
SlidingWindowLimit: settings.AppMessageSlidingWindowRate,

// After (fixed):
var slidingLimit int
if settings.AppMessageSlidingWindow {
    slidingLimit = settings.AppMessageSlidingWindowRate
}
// ...
SlidingWindowLimit: slidingLimit,
```

**Files Modified**:
- `cmd/init.go` (lines 746-768) - Fixed sliding window initialization
