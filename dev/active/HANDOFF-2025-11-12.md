## Key Technical Insights

### Progress Bar Fix Lesson
When fixing bugs that span multiple layers:
1. Check BOTH SQL queries AND Go code
2. Fixing just one layer may not be enough
3. Paused campaigns are still "active" and need stats
4. Database queries are most reliable for verification
